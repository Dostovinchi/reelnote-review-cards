Export your Serializd diary

Serializd is refusing requests sent from the GitHub Pages site. This helper runs only after you open Serializd itself, then downloads a JSON file that Framix can read locally.

  1. Open Serializd in this browser and sign in normally if needed.
  2. Drag the purple Export Serializd diary link below to your bookmarks bar. If the bar is hidden, press Ctrl + Shift + B.
  3. Open your Serializd profile or diary page, then click the bookmark you just saved. It tries the public diary first. If Serializd returns 401, it opens a login form and submits those credentials directly to Serializd's API — never through Framix or a public proxy.
  4. When the file downloads, return to Framix, find the Serializd section, and select the downloaded serializd-diary-….json file under “Import a JSON / CSV diary file.”
Export Serializd diary ↗
Privacy: the bookmarklet does not contact a Framix backend or save the password. If you choose to sign in through its form, the request goes over HTTPS directly to serializd.onrender.com/api/login. Review the source code before using any bookmarklet that requests credentials.

If the bookmarklet reports a CORS/network error, Serializd is blocking browser access from its own profile page too. In that case the remaining reliable option is a locally generated export from a trusted CLI tool, not another public proxy.
